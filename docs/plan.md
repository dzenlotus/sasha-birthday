# План реализации открытки — v3.2

Основание: [спецификация v3.2](./specification.md). Добавлена выбранная пользователем «Rishab Rikhiram Sharma — Chanakya (Live from Mumbai)», YouTube `KBYSpR8N6pc`, через видимый плеер по явному нажатию. Сценарий и оформление открытки сохранены. Локальные результаты и ограничения — в [verification.md](./verification.md); проверка опубликованной версии записывается отдельно. Сайт сохраняет статическую архитектуру без сборки и backend.

## Ответственность файлов

| Файл | Ответственность |
| --- | --- |
| `index.html` | Русский язык документа, метаданные и растровый ImageGen favicon, семантический каркас полноэкранной сцены без верхнего header/menu, нижняя навигация, отдельные кнопки эффектов/музыки и постоянная панель плеера вне `#story`, подключение стилей, сообщение при отключённом JavaScript. |
| `style.css` | Палитра midnight teal/emerald/champagne gold/coral, типографика и сцена ночного сада, адаптация Aurora Text и Shimmer Button в CSS, нижняя навигация, фокус, состояния загадок, лотос, статичное праздничное сообщение и reduced motion. |
| `app.js` | Переходы и доступность глав, состояния загадок, сохранение с fallback, фокус и live feedback, эффекты по согласию, пожелания и скачивание; подключение атмосферы, финальных модулей и `music.js` без пересоздания плеера при смене главы. |
| `music.js`, `music.css` | Ленивая загрузка официального YouTube API по нажатию, видимый iframe ≥200×200 вне `#story` и выше shader/petals, реальные статусы `PLAYING`, плавная начальная громкость 30%, остановка/закрытие и отмена до `onReady`, сообщение об ошибке со ссылкой YouTube, адаптация панели. |
| `effects.js` | Нативный WebGL fragment shader света и частиц, cursor/touch/ripple, запуск и пауза атмосферы по видимости вкладки, статичный fallback, параметры декоративных CSS-эффектов. Игровые состояния остаются в `app.js`. |
| `letter.js`, `letter.css` | Открытие конверта около 750 ms, первый абзац и отдельная иллюстрация, кнопка «Развернуть письмо», три складываемые панели и полный текст локальным Caveat с кириллицей, статичные состояния при reduced motion. |
| `candles.js`, `candles.css` | Три объёмные свечи и пламя в нативном WebGL, один переиспользуемый контекст/цикл, отдельное гашение нажатием/касанием и клавиатурой, статичные fallback-кнопки, пауза скрытой вкладки. |
| `petals.js` | `startPetalWind()` запускает примерно 10 секунд ветра с кружащимися WebGL-лепестками rose/coral/champagne; конечный цикл, декоративный `aria-hidden` слой без перехвата ввода, статичное сообщение при reduced motion/отказе WebGL. |
| `content.js` | Личные тексты, письмо, названия глав, инструкции, подсказки, подписи символов, намерения и подготовленные пожелания. |
| `assets/` при необходимости | Лунный сад, отдельная иллюстрация письма, прозрачный атлас 12 иконок ImageGen, отдельный лотос, растровый favicon и локальные шрифты, включая Caveat с кириллицей. |
| Раздел источников в документации проекта | Источники адаптаций Magic UI Aurora Text и Shimmer Button, необходимая атрибуция исходных материалов. |
| `docs/specification.md` | Контракт поведения и проверяемые требования. |
| `docs/plan.md` | Порядок работ, ответственность и матрица приёмки. |
| Конфигурация GitHub Pages при необходимости | Публикация статических файлов и воспроизводимый адрес открытки. |

## Порядок работ

Дополнение v3.2 выполняется поверх опубликованной v3.1:

1. **Добавить управление музыкой.** Подключить `music.css` и импорт `music.js` из `app.js`, добавить кнопку «Музыка» рядом с эффектами и постоянную панель вне `#story`. До нажатия не создавать iframe/API и запросы YouTube. Сохранить видимый плеер ≥200×200 со штатными controls и корректными origin/referrer.
2. **Подключить воспроизведение.** По явному нажатию загружать выбранное видео стандартным embed. Сообщать «Играет» только после `PLAYING`, при необходимости просить Play в самом плеере; плавно доводить начальную громкость до 30% примерно за 1,2 секунды. При смене главы сохранять iframe и позицию. Выключение/закрытие останавливает звук; поздний `onReady` после закрытия не запускает его.
3. **Проверить и опубликовать музыку.** Пройти новые строки MUSIC-01/AUDIO-01 ниже, включая настоящий click, переход главы, закрытие до готовности API, ошибку и 320 px. При ошибке показать ссылку на YouTube и оставить открытку рабочей. После публикации повторить основной музыкальный путь и записать результаты отдельно от v3.1.

Предыдущий план v3.1 сохранён для связи с реализованным сценарием:

1. **Подготовить иконки и ресурсы v3.** Сгенерировать прозрачный атлас 12 иконок и отдельный лотос, заменить line SVG/символьные иконки во всех главах, навигации и управляющих элементах, подключить растровый favicon ImageGen. Сохранить функциональные подписи и ARIA-имена. Подготовить отдельную иллюстрацию письма и локальный Caveat с кириллицей.
2. **Собрать интерактивное письмо.** В `letter.js`/`letter.css` реализовать конверт с открытием около 750 ms, первый абзац с иллюстрацией и кнопку «Развернуть письмо». Раскрыть три складываемые панели с полным настоящим текстом страницы. После разворачивания открыть свечи, пожелания и скачивание; при reduced motion показывать те же состояния статично.
3. **Сделать объёмные свечи.** В `candles.js`/`candles.css` отрисовать объёмный воск и пламя трёх свечей через нативный WebGL, используя один контекст и цикл для всех трёх. Подключить индивидуальное гашение через tap/click и клавиатурные кнопки, однократный подсчёт, паузу скрытой вкладки и статичный fallback без WebGL/reduced motion. Микрофон не нужен.
4. **Соединить модули и сохранить сценарий.** Подключить новые модули к финалу `app.js`. Заменить прежний эффект праздника вызовом `startPetalWind()` при гашении третьей свечи: около 10 секунд лепестков, переносимых ветром через экран. Проверить прежний последовательный путь, четыре задания, подсказки, пропуск, пожелания, скачивание и сохранение с fallback. Сохранить ночной сад, WebGL-атмосферу, Magic UI и нижнюю навигацию. Проверить фокус, live feedback, Tab-порядок и читаемость рукописного текста на телефоне.
5. **Проверить и опубликовать v3.1.** Пройти матрицу ниже на локальном статическом сервере, исправить найденные проблемы, затем обновить GitHub Pages. Открыть опубликованный адрес и повторить основной сценарий, включая открытие/разворачивание письма, свечи, триггер/конечность лепестков, fallback, перезагрузку и скачивание. Новые результаты записать отдельно от проверки v2 без заявления о непроверенных платформах.

## Критерий готовности

Все требования имеют подтверждённый результат проверки, личный текст вычитан, опубликованный адрес открывается и основной путь работает на нём. Непройденные проверки и известные ограничения перечисляются прямо; визуальный осмотр одного браузера не считается проверкой всех устройств.
