# План реализации открытки — v3.5

Основание: [спецификация v3.5](./specification.md). По точному указанию пользователя YouTube-контейнер получает `position:absolute; left:-10000px; top:0; width:320px` и остаётся отрисованным при воспроизведении. Это заменяет inline-размещение v3.4. Видимое управление остаётся в dock; одобрение размещения правилами YouTube не заявляется. Предыдущие результаты сохранены в [verification.md](./verification.md), новые проверки ниже запланированы.

Источник `2dBHTz6g5AM`, CTA «Поехали с музыкой», fade до 70%, ползунок 0–100, личный текст v3.3, шесть глав, изображения, письмо, WebGL-свечи и лепестки сохраняются. Сайт остаётся статическим, без сборки и backend. Аудио не скачивается, не извлекается и не перепубликуется; API, географические ограничения и авторизация не обходятся.

## Порядок работ

1. **Применить точную геометрию.** Разместить контейнер `absolute` на `left:-10000px; top:0` с шириной 320 px. При игре сохранять отрисовку без `display:none`. Установить `aria-hidden` и `inert`, убрать прежний scroll-to-inline/native-controls путь. Проверить отсутствие горизонтального переполнения.
2. **Сохранить видимое управление.** Музыка on/off использует `aria-pressed`; range0–100 и процент видны при активной музыке, эффекты управляются отдельно. Off/close сначала останавливает источник, затем скрывает его и range. При браузерном блоке «Включить музыку» повторяет запуск готового API через реальный click; при ошибке доступно «Открыть YouTube». Не добавлять имитацию жестов или новые способы обхода.
3. **Проверить и опубликовать v3.5.** Выполнить матрицу ниже на 320 px и широком экране. Реальный media time должен продолжать расти после смены главы при том же iframe. Повторить CTA-старт, громкость, выключение и fallback на опубликованной версии; записать результаты отдельно от предыдущих проверок.

## Критерий готовности

Новая геометрия и настоящее воспроизведение проверены, dock доступен, закрытие/fallback работают, опубликованная версия открывается. Непроверенные платформы и ограничения перечисляются прямо; соответствие правилам YouTube не утверждается.
