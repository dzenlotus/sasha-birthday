# План реализации открытки — v3.3

Основание: [спецификация v3.3](./specification.md). Официальная музыкальная версия «Rishab Rikhiram Sharma — Chanakya (Official Music Video)», YouTube `2dBHTz6g5AM`, запускается с первой главной CTA, без отдельного нажатия «Музыка» там, где браузер разрешает. Начальный fade — до 70%, собственный ползунок — 0–100 с процентом. Личный текст становится коротким и разговорным: «Сашечка», «родная», без титулов, официоза и удалённых шаблонов. Шесть глав, изображения, WebGL, письмо и лепестки сохраняются. Проверки v3.3 запланированы; результаты предыдущих версий — в [verification.md](./verification.md). Статическая архитектура без сборки и backend сохраняется.

## Ответственность файлов

| Файл | Ответственность |
| --- | --- |
| `index.html` | Русский язык документа, простые личные metadata и текст без удалённых подписей, растровый ImageGen favicon, семантический каркас полноэкранной сцены без верхнего header/menu, нижняя навигация, ручное управление эффектами/музыкой и постоянная панель плеера вне `#story`, подключение стилей. |
| `style.css` | Палитра midnight teal/emerald/champagne gold/coral, типографика и сцена ночного сада, адаптация Aurora Text и Shimmer Button в CSS, нижняя навигация, фокус, состояния загадок, лотос, статичное праздничное сообщение и reduced motion. |
| `app.js` | Первая главная CTA открывает главу 1 и вызывает `startMusic()`; дальнейшие переходы сохраняют iframe и ручное выключение музыки. Переходы, загадки, сохранение, фокус, live feedback, эффекты, пожелания, скачивание и подключение визуальных модулей сохраняются. |
| `music.js`, `music.css` | Официальный embed `2dBHTz6g5AM`, загрузка API с первого действия, видимый iframe ≥200×200 вне `#story`, реальные статусы `PLAYING`, native Play при блоке браузера; fade до 70%, ползунок 0–100 с процентом и немедленной отменой fade, сохранение громкости между главами в сессии, выключение/закрытие, guard до `onReady` и сообщение об ошибке со ссылкой YouTube. |
| `effects.js` | Нативный WebGL fragment shader света и частиц, cursor/touch/ripple, запуск и пауза атмосферы по видимости вкладки, статичный fallback, параметры декоративных CSS-эффектов. Игровые состояния остаются в `app.js`. |
| `letter.js`, `letter.css` | Открытие конверта около 750 ms, первый абзац и отдельная иллюстрация, кнопка «Развернуть письмо», три складываемые панели и полный текст локальным Caveat с кириллицей, статичные состояния при reduced motion. |
| `candles.js`, `candles.css` | Три объёмные свечи и пламя в нативном WebGL, один переиспользуемый контекст/цикл, отдельное гашение нажатием/касанием и клавиатурой, статичные fallback-кнопки, пауза скрытой вкладки. |
| `petals.js` | `startPetalWind()` запускает примерно 10 секунд ветра с кружащимися WebGL-лепестками rose/coral/champagne; конечный цикл, декоративный `aria-hidden` слой без перехвата ввода, статичное сообщение при reduced motion/отказе WebGL. |
| `content.js` | Короткие разговорные тексты с обращением «Сашечка»/«родная», четыре абзаца письма из подтверждённых фактов и простых пожеланий, названия глав, инструкции и подсказки; удаление приторных шаблонов и религиозных титулов. |
| `assets/` при необходимости | Лунный сад, отдельная иллюстрация письма, прозрачный атлас 12 иконок ImageGen, отдельный лотос, растровый favicon и локальные шрифты, включая Caveat с кириллицей. |
| Раздел источников в документации проекта | Источники адаптаций Magic UI Aurora Text и Shimmer Button, необходимая атрибуция исходных материалов. |

## Порядок работ

Дополнение v3.3 выполняется поверх опубликованной v3.2:

1. **Переписать личный текст.** Обновить `content.js`, видимый текст `index.html`/письма и metadata. Убрать все перечисленные в TXT-01 фразы и подобные шаблоны, обращаться «Сашечка»/«родная», оставить четыре коротких разговорных абзаца письма. Проверить каждое личное утверждение по фактам, сохранить простые подписи действий и существующую навигацию.
2. **Связать начало и музыку.** В обработчике первой главной CTA открыть главу 1 и вызвать `startMusic()` для официального клипа `2dBHTz6g5AM`. До этого действия не загружать YouTube; отдельное нажатие «Музыка» для начала не требовать. Добавить fade до 70% за ~1,2 s и ползунок 0–100 с процентом: ручное изменение сразу меняет громкость и прекращает fade, значение сохраняется между главами в сессии. Сохранить видимый плеер, честный `PLAYING`, native Play при ограничении браузера, ручное выключение, guard закрытия до `onReady` и тот же iframe между главами. Переходы после ручного выключения музыку не запускают. Аудио не извлекается и не перепубликуется; отдельный фон без YouTube возможен с предоставленным разрешённым аудиофайлом.
3. **Проверить и опубликовать v3.3.** Пройти новые строки TXT-01/CH-00/MUSIC-01 ниже, включая источник, реальный первый click, fade/ползунок, отсутствие ранних запросов, поведение при блоке браузера, ручное выключение и дальнейшие переходы. Отсутствие любых произнесённых слов без полного прослушивания не заявлять.

## Критерий готовности

Все требования имеют подтверждённый результат проверки, личный текст вычитан, опубликованный адрес открывается и основной путь работает на нём. Непройденные проверки и известные ограничения перечисляются прямо; визуальный осмотр одного браузера не считается проверкой всех устройств.
