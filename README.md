# Саша, с днём рождения!

Личная интерактивная открытка: ночной сад, индийский танец, итальянское настроение, четыре лёгкие загадки, разворачивающееся рукописное письмо и объёмные свечи. После третьей свечи ветер подхватывает лепестки.

**Сайт:** https://dzenlotus.github.io/sasha-birthday/

## Локальный запуск

Нужен Python 3. Устанавливать зависимости не требуется.

```sh
npm start
```

Открыть http://127.0.0.1:4173. Можно также запустить `python3 -m http.server 4173` из этой папки.

## Проверки

```sh
npm test
```

Это девять тестов состояния на встроенном `node:test`. Для браузерной проверки открыть свежую открытку в отдельном профиле, вставить функцию из `tests/browser-check.js` в консоль и вызвать `await runBirthdayAcceptance()`.

## Публикация

GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает обработку Jekyll. Все адреса ресурсов относительные, сборка и сервер не нужны. Изменения публикуются после push в `main`.

## Редактирование

Поздравление, пожелания и тексты загадок находятся в `content.js`. Открытые главы сохраняются в этом браузере. Неполные задания и раскрытое письмо при перезагрузке могут начаться заново. Никакие ответы или желания не отправляются на сервер.

Шрифты, иллюстрации и все созданные в ImageGen иконки хранятся локально. Лицензии шрифтов включены в `assets/`. Настоящий GLSL-шейдер работает в `effects.js`; Aurora Text и Shimmer Button адаптированы из официальных исходников Magic UI в обычный CSS без React.

Письмо и его сгибы — в `letter.js`/`letter.css`; свечи — настоящий WebGL в `candles.js`; поток лепестков — в `petals.js`.
